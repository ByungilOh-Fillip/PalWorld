# Save Hooks

목표는 월드 시스템이 저장에 필요한 데이터만 제공하고 저장 시스템 구현체에 강하게 묶이지 않게 하는 것이다.

## 저장 대상

| 대상 | 저장 여부 | 이유 |
|---|---|---|
| CurrentDay | 저장 | 월드 시간 유지 |
| CurrentTimeOfDay | 저장 | 낮/밤 상태 유지 |
| TemperatureVolume 설정 | 기본 제외 | 에디터 배치 데이터로 충분 |
| Runtime Temperature 변경 | 필요 시 저장 | 동적 이벤트가 생긴 뒤 판단 |
| Wild Pal 개별 상태 | 1차 제외 | 임시 필드 액터로 취급 |
| Spawn Timer | 제외 | 로드 후 새로 계산 |
| Work Slot 점유 | 1차 제외 | 일시적 작업 예약 |
| Work Progress | 필요 시 저장 | 장기 작업 건물이 생긴 뒤 판단 |

## 구현 항목

- [ ] 월드 시간 저장 데이터 제공
- [ ] 필요 시 온도 볼륨의 런타임 변경 상태 제공
- [ ] 작업 건물 슬롯 상태 저장 여부 결정
- [ ] 작업 건물 진행률 저장 여부 결정
- [ ] 저장 DTO 정의
- [ ] 저장 대상과 런타임 Actor 분리

## 설계 원칙

- Actor 포인터를 직접 저장하지 않는다.
- 저장 데이터는 복원 가능한 ID와 값 중심으로 구성한다.
- 임시 스폰 타이머와 일시적 작업 예약은 기본 저장 대상에서 제외한다.
- 저장 시스템이 월드 상태 내부 구현에 직접 의존하지 않게 한다.

## 완료 기준

- [ ] 저장 시스템이 월드 시간 값을 가져갈 수 있음
- [ ] 로드 시 월드 시간을 복원할 수 있음
- [ ] 스폰 타이머 같은 임시 상태를 저장하지 않음
