- [ ] `PalWorld/Source/PalWorld/LMK/Public` 아래에 공개 헤더 작성
- [ ] `PalWorld/Source/PalWorld/LMK/Private` 아래에 구현 파일 작성
- [ ] 새 프로젝트 코드 식별자에 `PW_` 접두사 적용
- [ ] 기존 공통 폴더나 다른 팀원 폴더를 직접 수정하지 않기
- [ ] 한 클래스가 하나의 책임만 갖도록 파일과 역할 분리
- [ ] 다른 시스템이 구체 클래스를 몰라도 되는 지점은 인터페이스로 분리
- [ ] 선택적 알림이나 비동기 결과 전달은 델리게이트로 처리

- [ ] 세션 작업 결과 델리게이트 정의
